# Canonical data files (repo is the source of truth; Postgres is derived)

Decision (2026-09-10, paradata P-001): the cited data lives in git as JSON so it is
reviewable by pull request and auditable by anyone. Neon Postgres holds a derived
mirror plus mutable state (users, events, saved tours). Exhibit text and claims are
also files here, approved via PR review, then seeded.

All files are generated by scripts in `scripts/` from the raw sources in `data/`.
Never hand-edit a generated file; fix the script or add a paradata row.

## data/tenants.clean.json

```jsonc
{
  "meta": { "generated_at": "ISO", "generator": "scripts/parse-cnn.ts", "tenant_count": 329 },
  "sources": [{
    "id": "cnn-2001-09-13",
    "citation": "CNN.com, \"List of World Trade Center tenants\" (tenant list provided by CoStar Group, Inc.), as archived by the Internet Archive on 2001-09-13",
    "url": "…original CNN URL if recoverable from the HTML, else null…",
    "archived_url": "…web.archive.org URL if recoverable, else null…",
    "retrieved_at": "2026-09-10",
    "local_files": ["data/cnn_t1.html", "…"]
  }],
  "buildings": [{ "id": "wtc1", "name": "1 World Trade Center", "cnn_label": "1 World Trade Center - North Tower",
                  "source_file": "data/cnn_t1.html", "column_order": ["tenant","sq_ft","industry","floor"],
                  "tenant_count": 203, "sq_ft_total": 0 }],
  "floor_codes": { "CNCR": "Concourse", "LBBY": "Lobby", "BSMT": "Basement", "GRND": "Ground",
                   "LL": "Lower level", "PLAZ": "Plaza" },
  "tenants": [{
    "id": "wtc1-001",                 // building id + 3-digit source row order
    "building_id": "wtc1",
    "name": "Strawberry",
    "sq_ft": 7106,                    // int, or null when source says N/A or blank
    "sq_ft_raw": "7,106",             // verbatim
    "industry": "Retailers/Wholesalers", // null when blank
    "industry_raw": "Retailers/Wholesalers",
    "floor_raw": "CNCR",              // verbatim, may be "" 
    "floors": ["CNCR"],               // expanded labels: "9-11,81" -> ["9","10","11","81"]; codes kept as-is
    "floor_unresolved": null,         // e.g. "CINDE" when a token is not a number, range, or known code
    "evidence": "documented",         // all CNN rows; see paradata P-017
    "source_id": "cnn-2001-09-13",
    "source_row": 5                   // 1-based row index within that building's CNN table
  }]
}
```

Rules: no field is ever inferred. Unknown floor tokens go in `floor_unresolved` verbatim
and `floors` gets only the tokens that resolved. Blank industry stays null (do not
classify). `sq_ft` "N/A" stays null.
